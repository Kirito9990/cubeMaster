# CubeMaster v0.2 · 色向中立 C+1 复盘 & 速拧计时训练系统

面向 Sub-8 / Sub-15 进阶魔方选手的 **C+1 (Cross + 1st F2L Pair)** 智能复盘、全色向中立 (Color Neutrality) 评估与 WCA 15 秒观察盲打计时训练系统。

## 新增核心特性 (v0.2)

1. **全色向中立支持 (6-Color Neutrality)**
   - 支持 **单色 (白底 `z2`)**、**双色 (白/黄底)**、**六色全中立 (白/黄/绿/蓝/红/橙 6底色 × 4朝向 = 24视角全局寻优)** 以及 **自由勾选底色**。
   - 跨底色 C+1 综合排行榜：直观对比各底色下的最少十字步数、最佳首组槽位与 C+1 综合得分，一键切换任意底色查看全部路线与 3D 演示。
2. **速拧计时与 15 秒观察盲打训练场 (Timer & Inspection Trainer)**
   - **双科目训练**：支持 `C+1 专项爆发 (十字+首组即停)` 与 `完整 3x3 还原计时`。
   - **WCA 15 秒观察倒计时**：内置 8 秒 / 12 秒声光提醒，15~17 秒自动判 `+2`，超过 17 秒自动判 `DNF`。
   - **盲打规划遮罩 (Blind C+1 Mask)**：开始计时后自动遮挡 3D 魔方，强迫选手凭观察期的脑内推演完成十字与首组 F2L，停表后自动揭开。
   - **实战决策打卡 vs 引擎最优解对比**：停表后标记自己实战选的【底色】与【首组槽位】，自动计算你的决策得分与引擎全场最优解的差距，并统计历史 **最优 C+1 命中率**、**Best**、**Ao5**、**Ao12**。

## 快速启动指南

### 1. 启动 Python 后端 (FastAPI)
```bash
pip install -r requirements.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000 --reload
```

### 2. 启动 Next.js 前端
```bash
cd web
npm install
npm run dev
```
浏览器访问 `http://localhost:3000` 即可使用。
