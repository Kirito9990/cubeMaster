# CubeMaster · C+1 解法拆解与 csTimer 速拧计时器

面向三阶魔方进阶练习的 **C+1（底十字 Cross + 第一组 F2L）解法拆解系统** 与 **独立 csTimer 风格速拧计时器**。

## 核心功能

1. **主力底色设置 + 六色底全中立对比**
   - 支持自由设置你的 **主力底面**（白底 / 黄底 / 绿底 / 蓝底 / 红底 / 橙底，自动保存）。
   - 默认优先展示你主力底面的最佳路线；同时可一键开启其余 5 色底横向对比，当其他底色出现超顺手好块时自动提示。
2. **极简清晰的 C+1 解法展示 +「📖 查看详细说明」逐步拆解**
   - 去除繁琐杂乱的标签，采用大字号三步卡片直观呈现：**① 起手怎么拿魔方 → ② 底十字（Cross）→ ③ 第一组 F2L**。
   - 点击任意路线或槽位上的 **「📖 查看详细说明」** 按钮，即可弹出大白话详解：做完十字后角块/棱块分别在哪里、如何配对与无转体入槽、为什么先做后槽能留出视野，以及每个字母记号的中文转动方向。
3. **独立全屏 csTimer 风格速拧计时器**
   - 点击顶部导航 **「⏱️ 速拧计时器 (csTimer)」**（或直接访问 `/timer`）即可进入独立大屏计时页面。
   - 支持空格长按 0.3s 变绿起跳、可选 WCA 15 秒观察倒计时（8s / 12s 蜂鸣提示）、计时过程自动隐去侧栏防干扰。
   - 左侧实时统计 `time`、`mo3`、`ao5`、`ao12`、`best`、`mean`，支持 `+2` / `DNF` / 删除，任意一把成绩均可一键点击 **「复盘」** 跳回 C+1 页面查看该打乱的详细解法。

## 快速启动

现在前端已内置 Python 求解引擎自动桥接，**只需启动前端即可直接使用全部功能**（无需开两个终端）：

```bash
cd /Users/andy/Desktop/Projects/CubeMaster/web
npm run dev
```

然后在浏览器打开 [http://localhost:3000](http://localhost:3000) 即可使用。

> 如果你也想单独启动 FastAPI 后端服务（可选）：
> ```bash
> cd /Users/andy/Desktop/Projects/CubeMaster
> uvicorn backend.app:app --reload --port 8000
> ```
